# 🧠 AI-Driven Expert System for Mental Health Assessment

An interactive expert system developed in Python that performs a comprehensive mental health assessment using a structured 50-question questionnaire. The application analyzes user responses through a rule-based scoring system, classifies mental wellness levels, generates a personalized assessment report, and supports CSV export for further analysis.

> **Disclaimer:** This project is intended for educational and research purposes only. It is **not** a medical diagnostic tool and should not replace consultation with qualified mental health professionals.

---

## 🚀 Features

* 📝 Interactive 50-question mental health questionnaire
* 🧠 Rule-based expert system for mental wellness assessment
* 📊 Automated scoring across multiple wellness categories
* 📈 Classification into Healthy, Mild, Moderate, or Severe concern levels
* 📋 Personalized assessment summary
* 💾 Export assessment results to CSV
* 🎛️ User-friendly interface built with Jupyter Widgets
* ⚡ Instant feedback after questionnaire submission


## 🧩 Assessment Workflow

1. Answer the 50 mental health questions.
2. Responses are evaluated using predefined rule-based logic.
3. Scores are calculated across wellness dimensions.
4. Overall mental wellness category is determined.
5. A personalized report is generated.
6. Results can be exported as a CSV file.
